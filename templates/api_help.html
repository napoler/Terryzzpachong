API Help

The application provides a JSON API for programmatic access to the torrent data.

Get Torrent by Info Hash

  • URL: /api/torrent/<info_hash>
  • Method: GET
  • Description: Retrieves the details of a single torrent.
  • Example: curl http://127.0.0.1:5000/api/torrent/YOUR_INFO_HASH

Search Torrents

  • URL: /api/search/<query>
  • Method: GET
  • Description: Searches for torrents matching the query, with optional filters.
  • URL Parameters (optional):
    • min_size (int): Minimum size in bytes.
    • max_size (int): Maximum size in bytes.
    • min_files (int): Minimum number of files.
    • max_files (int): Maximum number of files.
    • sort_by (string): Field to sort by. Can be name, size, or files. Default is name.
    • sort_order (string): Sort order. Can be asc or desc. Default is asc.
  • Example: curl "http://127.0.0.1:5000/api/search/ubuntu?min_size=1000000000&sort_by=size&sort_order=desc"

Get Latest Torrents

  • URL: /api/latest
  • Method: GET
  • Description: Retrieves a list of the most recently discovered torrents, with optional sorting and limit.
  • URL Parameters (optional):
    • limit (int): Number of torrents to return. Default is 50.
    • sort_by (string): Field to sort by. Can be id, name, size, or files. Default is id.
    • sort_order (string): Sort order. Can be asc or desc. Default is desc.
  • Example: curl "http://127.0.0.1:5000/api/latest?limit=10&sort_by=size"
